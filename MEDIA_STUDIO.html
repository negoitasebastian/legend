GTP2 MEDIA STUDIO

Build your own local media pack for 36 locations (interiors and exteriors) and 28 human-recorded voice clips. The game itself stays usable without a media pack; only approved captures can unlock the photo clues. It runs entirely in your browser: files never leave your computer.

Use only media you are authorized to include in your fan project. If a Wiki page redirects or denies hotlinking, open the source page and download the image yourself. The exporter never generates or claims to have gameplay screenshots. Only add images and human recordings you are permitted to publish.

Ready to export?

Your download will contain assets/maps/*, optional assets/voices/*, and a voice manifest. Extract the ZIP into your new GTP2 GitHub Desktop repository at its top level. Keep the existing .git folder, commit and push. GitHub Pages will serve these files from the same host as the game.
